Long key names break identity

Measured 372px overflow in the identity header and mid-glyph clipping in the key list with a realistic production name. The operator loses the exact object being operated on.

FIX: Elide display names (middle elide) with full-name tooltips on header and list rows; give the name row priority over badges.
P1

Splitter can erase the workbench

Vertical splitter dragged the workbench pane to 0 height (sizes [0, 618]) with no recovery except a blind re-drag.

FIX: setChildrenCollapsible(False) on the vertical splitter plus a minimum height on the workbench side.
P1

Meta rows wrap under the label column

Wrapped fingerprint and path values hang back under their labels, with an orphaned fragment on the first line.

FIX: One self-contained wrapped QLabel per meta row (inline bold prefix + mono value) so continuation lines align under the value.
